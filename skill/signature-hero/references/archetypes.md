# 업종별 심장 품목 · 조작 표

✅ = 실제로 만들어 유저 확인까지 받은 것. 나머지는 설계안 — 만들고 나면 ✅와 메모를 추가한다.

| 업종 | 심장 품목 | 인트로 (조작 = 진행) | 히어로 배경 (계속 반응) | 구현 | 소리 |
|---|---|---|---|---|---|
| ✅ 키보드·기계식 | 키캡 / 키보드 | 브랜드명 키캡을 누를 때마다 한 글자씩 불 켜짐 → 다 켜지면 튀어오름 | 기울어진 풀 키보드. 커서 지나간 키 눌림+물결, 실제 키 입력 동기화, 커서 따라 오렌지 빛 | DOM 2.5D | 타건음 |
| 도자기·그릇 | 물레 위 그릇 | 드래그/스크롤로 물레를 돌리면 흙덩이가 그릇 모양으로 올라옴 → 완성되면 유약 색이 입혀지며 열림 | 천천히 도는 그릇 실루엣 + 손 그림자, 드래그하면 회전 속도·물레 자국 변화 | Canvas 2D(회전체 프로파일 라인) | 선택: 물레 저음 |
| 스킨케어·화장품 | 세럼 방울 | 탭할 때마다 스포이트에서 방울이 떨어져 수면이 차오름 → 가득 차면 물결이 화면을 덮으며 열림 | 잔잔한 수면. 커서/탭 위치에 물결 번짐, 가끔 자동 방울 | Canvas 2D 파동(높이맵) | 물방울 |
| 카페·커피 | 드립 주전자 / 원두 | 누르고 있는 동안 물줄기가 떨어져 컵이 참 → 김이 올라오며 열림 | 김이 피어오르는 컵. 커서가 김을 흩뜨림 | Canvas 2D 입자 | 선택: 물 붓는 소리 |
| 꽃집·플라워 | 꽃 한 송이 | 탭할 때마다 꽃잎이 하나씩 펴짐 → 만개하면 꽃잎이 흩날리며 열림 | 흩날리는 꽃잎 층. 커서 주변 꽃잎이 바람처럼 비켜감 | DOM/SVG 꽃잎 + transform | 없음 |
| 와인·위스키 바 | 잔 속 술 | 드래그로 잔을 돌리면 술이 벽을 타고 돎(레그) → 잔이 기울며 열림 | 어두운 바, 잔에 맺힌 빛. 커서 위치로 조명이 이동, 잔 속 액면이 기울기 따라 출렁 | Canvas 2D / WebGL 굴절 | 잔 부딪힘 |
| 패션·의류 | 원단 | 드래그하면 원단이 당겨지며 브랜드명이 드러남 | 화면을 덮는 천. 커서가 지나가면 주름이 밀림 | WebGL 천 시뮬(격자) 또는 Canvas 격자 | 없음 |
| 베이커리 | 반죽 | 누를수록 반죽이 부풀어 빵이 됨 → 갈라지며 열림 | 김·가루 입자, 커서로 가루를 털어냄 | Canvas 2D | 없음 |
| 치과·클리닉 | 치아 모형 / 칫솔 | 문지르면 표면이 반짝이며 깨끗해짐 → 빛이 번지며 열림 | 서늘한 빛이 커서 따라 표면을 훑음 (breathing-light mint + 모형 사진) | DOM + 마스크 | 없음 |
| 필라테스·요가 | 호흡 (물건 대신 몸의 리듬) | 원이 숨 쉬고 창처럼 열림 | 창가 빛·잎 그림자 | **breathing-light 스킬** | 없음 |
| 자동차·모빌리티 | 헤드라이트 / 핸들 | 누르고 있으면 시동·계기판이 켜짐 → 라이트가 켜지며 열림 | 어두운 도로, 커서가 라이트 방향 | Canvas/WebGL 광원 | 엔진 시동 |
| 게임·굿즈 | 캐릭터/주사위 | 탭하면 주사위가 굴러 브랜드 글자 면이 나옴 | 떠다니는 굿즈, 커서에 끌려옴 | DOM 3D transform | 효과음 |

## 새 업종을 정할 때 체크
- 그 물건을 **실제로 다루는 동사**인가? (키보드를 "돌리는" 건 어색하다)
- 조작 없이도 3초 안에 스스로 끝나는가?
- 히어로에서 물건이 텍스트 반대편에 설 자리가 있는가?
- 폰에서 손가락으로도 되는가? (호버 전용 반응은 탭 대체를 둔다)
