# 실제로 밟은 함정 (keyforge · align-pilates · 웹마켓, 2026-09-17)

1. **흔한 CSS 변수명 충돌** — 키캡 폭을 `--w`로 했다가 사이트의 `--w:1400px`(최대 폭)를 물려받아 폭 0이 됨. 글자만 보이고 키캡이 사라짐. → 접두사 변수(`--kw`).
2. **흔한 클래스명 충돌** — `.btn.line`↔장바구니 `.line`, `.btn.sec`↔섹션 `.sec`. → 접두사 클래스(`kf-`).
3. **`const`는 window에 안 붙음** — 앞 스크립트에서 `window.KF?.mountHero()`를 불렀는데 `const KF`라 undefined → 히어로가 안 그려짐. → `window.KF = ...`.
4. **인라인 script 안의 닫는 태그 문자열** — 주석에라도 있으면 태그가 끊겨 SyntaxError, 인트로가 안 열림. → 인라인 후 `node --check`, CSS 안전장치(10초 강제 해제).
5. **SPA/해시 라우터 재렌더** — 홈 HTML이 다시 그려지면 붙여둔 요소·리스너가 사라짐. → 렌더 직후 mount 재호출, 전역 리스너는 모듈 로드 시 1회.
6. **렌더 순서** — 앱 스크립트의 첫 `route()`가 모듈 스크립트보다 먼저 돌면 모듈이 없다. → 첫 route를 `DOMContentLoaded`로.
7. **텍스트 레이어가 포인터를 먹음** — 히어로 글씨 컨테이너가 화면 폭 전체라 뒤 물건이 반응 안 함. → 컨테이너 `pointer-events:none`, 링크·버튼만 auto. 그라디언트 `::after`도 none.
8. **효과가 약해서 "바뀐 게 없다"** — 켠/끈 비교 스크린샷 필수(breathing-light 1차 배포 교훈).
9. **폰에서 과함** — 세로 화면에선 빛·물체가 상대적으로 커져 글씨를 덮는다. 폰 전용 크기·세기 값을 따로 둔다.
10. **호버 전용 반응** — 터치엔 호버가 없다. `pointerdown`도 같이 받고, 안내 문구를 `hover:none`에서 "탭"으로.
11. **소리 자동재생 정책** — 첫 사용자 제스처 전 AudioContext는 무음. 자동 진행 초반이 조용한 건 정상. 끄기 버튼 필수.
12. **Space로 페이지가 내려감** — 히어로에서 키 입력을 받을 때 Space·화살표는 `preventDefault`.
13. **헤드리스 캡처 타이밍** — swiftshader는 느리다. 애니메이션은 `getAnimations()`로 멈추고 `currentTime`을 옮겨 찍거나, 실제 크롬으로 확인.
