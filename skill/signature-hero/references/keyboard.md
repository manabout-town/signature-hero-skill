# 레퍼런스 1호 — KEYFORGE 키보드 (2026-09-17)

사이트: ~/Desktop/웹마켓/keyforge-keyboards (다크모드, 배경 #0b0c0e, 포인트 #ff6a1a). 코드: `assets/keyboard/`.

## 키캡 한 개 (2.5D)
- `.kc` 바깥 상자(클릭 판정·폭) + `i` 윗면. 두께는 `box-shadow: 0 var(--h) 0 옆면색, 0 (h+2px) 0 바닥색, 0 (h+12px) 18px 그림자`.
- 평소 윗면은 `translateY(-h)`로 떠 있고, `.down`이면 `-h*.12`로 내려가며 그림자도 줄어듦 → 눌림.
- `.lit` = 글자 오렌지 + `::after` 오렌지 방사형 빛(키 아래로 새는 백라이트). `.wave` = 반쯤 눌림(물결용).
- 크기: `--u`(1u 키 크기) · `--gap` · `--kw`(몇 u짜리 키인지). 스페이스 6.25u, 엔터 2.25u 등 실제 배열 비율.

## 히어로 키보드
- `ROWS` 배열: `[라벨, event.code, 폭u, 클래스]` 5줄, 줄마다 합 15u. `data-x`(키 중심 u좌표)·`data-y`(줄) 저장 → 물결 거리 계산.
- 보드: `perspective:1700px` 부모 안에서 `rotateX(48deg) rotateZ(-17deg)`, 데스크톱 left 40% top 16%, 폰은 왼쪽 위로 크게.
- 반응: `pointerover`(살짝) · `pointerdown`(세게) · 전역 `keydown`(e.code로 같은 키, 누르는 동안 유지) · 반경 2.8u 이내 키에 거리×55ms 지연 물결.
- 히어로가 화면에 보일 때만 키 입력을 받음(IntersectionObserver), 입력칸 포커스·⌘/Ctrl 조합은 무시, Space/화살표는 스크롤 막음.
- 배경: 커서 위치(`--gx/--gy`) 오렌지 빛 + 오른쪽 위 따뜻한 빛 + 어두운 바탕. 텍스트 쪽은 `.hero::after` 그라디언트(왼쪽·아래 짙게).
- 텍스트 레이어 `.wrap{pointer-events:none}` + 안의 링크/버튼만 auto → 글씨 뒤 키도 커서에 반응.
- 해시 라우터라 홈이 다시 그려질 때마다 `KF.mountHero()`.

## 인트로
- 브랜드명 8글자 키캡(F만 포인트색), `--p`(0~1)로 바닥 빛 크기·진행바.
- 키 입력/탭 → 다음 글자 눌림. 0.8초 뒤부터 0.5초 이상 조작이 없으면 0.26초 간격 자동 진행 → 약 3초에 완료.
- 완료: 전부 켜짐 → 키캡이 순서대로 위로 튀어오르며 사라짐 → 오버레이 페이드 → `html.kf-open` → 히어로 G키 물결.
- 건너뛰기: Skip 버튼·휠. 안전장치: CSS로 10초 뒤 강제로 걷힘. 터치 기기는 안내 문구 "화면을 탭해보세요".

## 타건음 (WebAudio 합성, 파일 없음)
- 60ms 감쇠 노이즈 → 대역통과(1.3~2kHz 랜덤) = "딸깍", 175→70Hz 사인 90ms = "톡".
- 28ms 이내 연속 재생 무시(호버로 긁을 때 소음 방지). 첫 pointerdown/keydown에서 AudioContext 생성.
- 끄기 버튼 상태는 localStorage `kf-mute`.
